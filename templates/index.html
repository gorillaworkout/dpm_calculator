One page, one run

There is nothing to choose. Open Generate D&W, upload the workbook, and every sheet is produced in a single pass — whether you are giving it a raw back-office export or a Template D&W you filled in yourself. Both are accepted.

The four calculated columns

These are written to the right of sheets D and W. Re-running overwrites them — they never stack up or duplicate.

Handling Fee Transaction × the rate found in the fee table, using the Deposit or Withdrawal column as appropriate
Xero Rate The daily rate in sheet Xero, matched on Paid Date + Currency
Xero USD Transaction ÷ Xero Rate
Forex Gain/Loss Xero USD − the existing USD column — the realised FX difference between CRM and Xero

Rates are never stored here

Fee rates and Xero rates are read from the file you upload, every single run. Nothing is cached or remembered between uploads, so when a rate changes you simply upload a workbook containing the new one — there is no setting to update and no template to rebuild first.

Always check “Missing Data” first

Every result contains a Missing Data sheet. If a rate or fee could not be found, the affected cells are left red and nothing is calculated for them — the report will look complete but the totals will be short. Open that sheet before circulating any numbers. When it reports “None” on every line, the run is clean.
