Generate D&W

Upload your D&W workbook and choose the report month. The calculator fills in Handling Fee, Xero Rate, Xero USD and Forex Gain/Loss, then builds all 14 report sheets in a single pass — whether you give it a raw back-office export or a Template D&W you filled in yourself.

Handling Fee Transaction × the rate found in the fee table, using the Deposit or Withdrawal column as appropriate
Xero Rate The daily rate in sheet Xero, matched on Paid Date + Currency
Xero USD Transaction ÷ Xero Rate
Forex Gain/Loss Xero USD − the existing USD column — the realised FX difference between CRM and Xero

Fee rates and Xero rates are read from the file you upload on every run — nothing is cached between uploads. Always open the Missing Data sheet first: if a rate could not be found, those cells stay red and their totals are short. When it reports “None” on every line, the run is clean.

Deal Segregator

Upload one or more MT5 Deals History exports — for example one file per month. Only closing trades (Entry = out) are kept, repeated Deal IDs across files are counted once, and the rows are grouped by account, country, desk, type, symbol and currency.

Daily Day-by-day totals for Volume, Commission, Fee, Swap and Profit
Monthly Summary The same figures rolled up per month, without the daily detail
Verifikasi Row counts per file, rows dropped, duplicates removed and overall totals

Both tools return one workbook, downloaded straight to your browser. Nothing is stored on the server after you download it.
